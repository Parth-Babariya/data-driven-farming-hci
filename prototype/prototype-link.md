# Prototype

## Local prototype

Open [`index.html`](index.html) in a browser. It uses the adjacent [`styles.css`](styles.css) stylesheet and `farmer-avatar.png` image.

## Prototype reference

The complete prototype export is available at [`prototype.pdf`](prototype.pdf). Additional screen references are in [`screenshots/`](screenshots/).

## GitHub Pages

After pushing this folder to GitHub, enable **Settings → Pages** and select the branch and `/root` folder containing `index.html`. The page will then be available from the repository’s GitHub Pages URL.
