# Data-Driven Farming HCI

An HCI project exploring how farmers can use accessible, data-informed tools for weather awareness, crop management, learning, community support, market access, and financial resources.

## Repository contents

- [`report/`](report/) - Final project report.
- [`research/`](research/) - User research, personas, and journey mapping.
- [`design/`](design/) - Information architecture and wireframes.
- [`prototype/`](prototype/) - HTML/CSS prototype, prototype PDF, and screen references.

## Prototype

Open [`prototype/index.html`](prototype/index.html) in a browser to view the included HTML/CSS prototype. The complete prototype reference is also available as [`prototype/prototype.pdf`](prototype/prototype.pdf).

## Main design areas

- Weather and climate information
- Crop management and soil health
- Market prices and finance
- Learning resources and traditional knowledge
- Farmer community and peer support
- Public resources, schemes, and issue reporting
- Privacy, language, offline access, and notifications
